# Инструкции для агентов

## Назначение
Репозиторий реализует легитимную автоматизацию возвратов и разрешённый сбор товарных данных. Перед работой найдите и загрузите подходящий `SKILL.md` из `.agents/skills/`; при отсутствии создайте узкий переносимый навык.

## Непреложные ограничения
1. Денежная операция требует human approval, идемпотентный ключ и неизменяемую запись аудита.
2. Никогда не коммитьте секреты. Используйте секрет-хранилище и ссылки на secret ID. Проверяйте изменения secret scanner до коммита.

## Работа из эфемерной среды
- Git — единственный источник кода/инфраструктурных деклараций; после каждого законченного атомарного изменения: тесты, коммит, push в защищённую ветку.
- Никакое важное состояние не должно зависеть от локального диска агента.
- Логи — структурированные, с `trace_id`, `case_id`, `actor_id`, `source_id`, без секретов и без полного PII.

## Параллельные агенты
- Работа может выполняться одновременно с разных машин и разными AI агентами.
- Перед началом каждого шага агент обязан проверить `STATUS.md`.
- Каждый агент обязан фиксировать текущий шаг, прогресс, блокеры и следующий шаг.
- Один агент — один ограниченный набор файлов. Ownership фиксируется в issue/PR.
- Не переписывать чужую историю и не делать force-push.

## Исследование перед действиями
Перед каждым существенным изменением агент обязан:
1. Проверить наличие подходящего навыка агента в доступных источниках.
2. Исследовать документацию, открытые репозитории и существующие решения.
3. Зафиксировать найденные решения и почему выбран текущий подход.

## Накопление навыков
Каждый успешный процесс, решение проблемы, архитектурный паттерн или исследовательский результат должен быть преобразован в reusable skill в `.agents/skills/`.

Skill должен содержать:
- назначение
- когда применять
- входные данные
- пошаговую процедуру
- примеры
- ограничения

## Статус и передача контекста
После каждого завершённого шага обновлять `STATUS.md`:
- активный агент
- текущая задача
- последний завершённый шаг
- изменённые файлы
- результаты исследования
- проблемы
- следующий шаг

Цель: новый агент должен продолжить работу без доступа к предыдущему чату.

## Definition of Done
1. Проверен и применён подходящий skill.
2. Выполнено исследование существующих решений.
3. Тесты и проверки пройдены.
4. Обновлены документы и статус.
5. Изменения сохранены через GitHub workflow.
